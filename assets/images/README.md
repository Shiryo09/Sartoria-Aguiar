# Diretório de Imagens e Mídias — Sartoria Aguiar

Este diretório organiza todos os recursos visuais, fotos de ateliê, amostras de tecidos e campanhas fotográficas.

## Estrutura Recomendada

```
assets/
├── icons/
│   ├── bespoke-suit.svg          # Ícone técnico de terno e lapela
│   ├── dress-shirt.svg           # Ícone técnico de camisa social italiana
│   ├── tailored-trousers.svg     # Ícone técnico de calça Gurkha com pregas
│   └── monogram-a.svg            # Selo do Monograma Real Aguiar
│
└── images/
    ├── aguiar-crest.svg          # Brasão oficial de herança (Est. 1928)
    ├── hero/                     # Fotografias principais de banner e ateliê (1920x1080px)
    ├── fabrics/                  # Macrofotografia de tecidos (Loro Piana, Zegna, Scabal)
    ├── products/                 # Fotos das peças sob medida (fundo neutro ou ambiente)
    └── avatars/                  # Fotos de perfil de clientes VIP (ex: Arthur Montgomery)
```

## Diretrizes Visuais de Alfaiataria (Heritage Luxury)

- **Estilo Fotográfico:** Iluminação quente e difusa, paleta sóbria (tons de linho, nogueira, carvalho, carvão e latão polido).
- **Formatos ideais:** `.webp` ou `.jpg` otimizados para web (compressão 85%) para fotos reais; `.svg` para ilustrações e monogramas vetoriais.
- **Resoluções:**
  - Banners principais: 1920x1080px (ou 2560x1440px para telas retina).
  - Cards de produto: 800x1000px (proporção 4:5 clássica de moda).
  - Amostras de tecidos: 600x600px (1:1).
